# آتلیه فانوس

- سایت اصلی: `index.html`
- پنل مدیریت (لینک جدا): `admin.html` یعنی `آدرس-سایت/admin.html`

فقط فایل‌ها را روی GitHub بگذار و GitHub Pages را روشن کن. نیازی به اجرای SQL نیست.
اولین بار که `admin.html` را باز می‌کنی، با ایمیل خودت حساب بساز و دکمه «ثبت من به‌عنوان مدیر» را بزن (فقط برای اولین نفر کار می‌کند).
